# 🧮 Calculadora Dinámica en Node.js

Proyecto que consiste en procesar operaciones matemáticas definidas mediante objetos JSON. El sistema está desarrollado en **Node.js** con **TypeScript** y utiliza **Jest** para pruebas automatizadas.

## 🚀 Instalación

1. Clona el repositorio:

```bash
  git clone https://github.com/tu-usuario/mi-calculadora-ts.git
  cd mi-calculadora-ts
```

2. Instala las dependencias:

```bash
  npm install
```

3. Ejecuta las pruebas:

```bash
  npm test
```

4. Ejecuta el sistema principal

```bash
  npm run dev
```

## ⚙️ Estructura del Proyecto

```bash
  /mi-calculadora-ts/
  ├── src/
  │   ├── processNode.ts
  │   ├── processMultipleNodes.ts
  │   └── index.ts
  ├── tests/
  │   └── processNode.test.ts
  ├── nodes.json                  # Archivo de ejemplo con operaciones, que puedes modificar
```
